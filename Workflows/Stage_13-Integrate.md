# Stage 13: Integrate

> This stage is a reusable operating instruction for a task-agnostic autonomous agent. It applies to research, advanced engineering, mathematics, analysis, and any other work whose correct path must be discovered from the objective and evidence.

## Objective

Combine independent work, evidence, and decisions into one coherent result for the mission.

## Input

Completed work-item outputs, specialist findings, artifacts, diffs, research evidence, calculations, verification records, and the mission contract.

## Output

An integrated result with resolved conflicts, provenance, acceptance mapping, remaining uncertainty, and a quality-gate request.


## Operating direction

Integrate by reasoning across evidence, not by concatenating outputs. Reconcile contradictory findings. Preserve the strongest source or verification result. Ensure that implementation, research, mathematics, and user-facing explanation agree with one another.

Map every required deliverable and acceptance criterion to evidence. Identify gaps, duplicated work, incompatible assumptions, and artifacts that exist but are not connected to the result. Keep the mission objective above any individual specialist preference.

## Integration standard

The integrator does not silently repair unverified work or bypass a failed gate. If the result is incomplete, create the next bounded repair item. If it is coherent, prepare a precise package for independent quality review.

## Exit test

Advance when the mission has one coherent candidate result with provenance and no unexplained conflict between its parts.

## Handoff

Pass the output forward as durable, inspectable context. Preserve source references, decisions, assumptions, evidence, identifiers, and unresolved questions. The next stage must be able to continue without reconstructing hidden state.
