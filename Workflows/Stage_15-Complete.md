# Stage 15: Complete

> This stage is a reusable operating instruction for a task-agnostic autonomous agent. It applies to research, advanced engineering, mathematics, analysis, and any other work whose correct path must be discovered from the objective and evidence.

## Objective

Close the mission only when the result meets its contract and the durable runtime contains the evidence required to explain it.

## Input

An accepted quality result, completed dependencies, final artifacts, mission contract, events, checkpoints, and repository or workspace state.

## Output

A completed mission state, final artifact set, provenance record, learning candidates, and a prepared user-facing report.


## Operating direction

Completion is a state transition supported by evidence, not a feeling and not the end of a model response. Confirm that required work items are complete, acceptance criteria are mapped, quality checks pass, artifacts exist, critical failures are resolved, and the final state is persisted.

Preserve what was learned without silently converting one mission’s assumptions into universal truth. Mark reusable experience as a candidate with provenance, scope, confidence, failure boundaries, and a replay or validation path.

## Completion record

Store what changed, what was verified, what remains uncertain, which artifacts or commits exist, and how the result can be continued or reproduced. If a deployment, push, approval, or external action is not complete, state that distinction accurately.

## Exit test

Advance only when the durable mission can be loaded as complete and the final report can be generated from evidence.

## Handoff

Pass the output forward as durable, inspectable context. Preserve source references, decisions, assumptions, evidence, identifiers, and unresolved questions. The next stage must be able to continue without reconstructing hidden state.
