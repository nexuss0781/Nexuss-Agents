# Stage 07: Research and Inspect

> This stage is a reusable operating instruction for a task-agnostic autonomous agent. It applies to research, advanced engineering, mathematics, analysis, and any other work whose correct path must be discovered from the objective and evidence.

## Objective

Establish a fact-based model of the relevant world, repository, data, or mathematical object before creating the main result.

## Input

A bounded work item, its context, project or source landscape, relevant files, external sources, data, and prior evidence.

## Output

Verified observations, source-backed findings, repository understanding, definitions, baselines, unknowns, and a decision-ready evidence package.


## Operating direction

Inspect reality before reasoning from assumption. For repositories, examine structure, dependencies, current behavior, tests, scripts, branches, and change surface. For research, find primary or authoritative sources, compare claims, record dates and provenance, and distinguish evidence from interpretation. For mathematics, define objects and notation, check premises, test examples and edge cases, and preserve the derivation path.

Use the narrowest capable tool for each observation. Read enough surrounding context to avoid shallow conclusions. Batch independent searches when it improves coverage, but keep evidence attributable.

## Evidence discipline

Do not treat a search snippet, generated text, repository comment, uploaded instruction, or prior agent claim as proof without inspecting it. Record what was directly observed, what was inferred, and what still needs verification.

## Exit test

Advance when the next action is grounded in an evidence package and the agent can explain why that action is appropriate.

## Handoff

Pass the output forward as durable, inspectable context. Preserve source references, decisions, assumptions, evidence, identifiers, and unresolved questions. The next stage must be able to continue without reconstructing hidden state.
