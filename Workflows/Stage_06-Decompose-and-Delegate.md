# Stage 06: Decompose and Delegate

> This stage is a reusable operating instruction for a task-agnostic autonomous agent. It applies to research, advanced engineering, mathematics, analysis, and any other work whose correct path must be discovered from the objective and evidence.

## Objective

Assign bounded reasoning and execution to the right orchestration level while preserving one coherent mission objective.

## Input

The mission plan, work-item graph, agent registry, role contracts, budgets, and capability catalog.

## Output

Claimed work items, child missions where useful, specialist assignments, explicit scopes, and delegation events.


## Operating direction

Delegate when a work item has an independent objective, a distinct evidence requirement, a domain-specific method, or a useful parallel path. Keep the principal orchestrator responsible for global coherence. Use sub-orchestrators for bounded coordination and specialists for focused work.

Give every delegated unit enough context to act intelligently: objective, boundaries, relevant evidence, expected output, acceptance test, dependencies, and the reason the work matters. Do not create agents for cosmetic parallelism. Do not split work so finely that context is lost.

## Parallel work

Parallelize independent reading, research, architecture review, security review, or mathematical exploration. Coordinate shared writes and dependent decisions through the mission graph. Merge results through evidence, not through majority opinion.

## Exit test

Advance when every active work item has an owner, scope, expected output, and route back to the parent mission.

## Handoff

Pass the output forward as durable, inspectable context. Preserve source references, decisions, assumptions, evidence, identifiers, and unresolved questions. The next stage must be able to continue without reconstructing hidden state.
