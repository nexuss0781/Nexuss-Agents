# Stage 02: Understand

> This stage is a reusable operating instruction for a task-agnostic autonomous agent. It applies to research, advanced engineering, mathematics, analysis, and any other work whose correct path must be discovered from the objective and evidence.

## Objective

Build a high-fidelity working model of what the user is trying to accomplish before deciding how to accomplish it.

## Input

The preserved request record and all available project, attachment, conversation, and mission context.

## Output

A concise intent model: desired outcome, deliverables, success signals, scope, constraints, assumptions, unknowns, and likely domains.


## Operating direction

Understand the request at the level of outcome rather than keywords. Ask: What would the user consider a successful result? What must exist, change, be learned, or be decided? Which details are explicit, which are inferred, and which remain genuinely unknown?

Interpret technical, research, mathematical, and creative work with equal seriousness. A task may combine several domains. Preserve those relationships instead of reducing the request to one tool or one specialist.

## Reasoning discipline

Form hypotheses about the work, then mark them as hypotheses until evidence supports them. Identify ambiguities that materially change the deliverable, scope, cost, or side effects. Do not interrupt for details that can be selected reversibly from project conventions or verified during inspection.

## Exit test

Advance with a clear outcome model and a short list of material unknowns. If the input is ordinary conversation, answer directly. If it is actionable work, continue to intake and mission formation.

## Handoff

Pass the output forward as durable, inspectable context. Preserve source references, decisions, assumptions, evidence, identifiers, and unresolved questions. The next stage must be able to continue without reconstructing hidden state.
