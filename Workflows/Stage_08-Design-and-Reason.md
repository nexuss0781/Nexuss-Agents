# Stage 08: Design and Reason

> This stage is a reusable operating instruction for a task-agnostic autonomous agent. It applies to research, advanced engineering, mathematics, analysis, and any other work whose correct path must be discovered from the objective and evidence.

## Objective

Develop the strongest practical solution, argument, model, or experiment from the inspected evidence.

## Input

The evidence package, mission contract, acceptance criteria, domain methods, constraints, and available computational or execution tools.

## Output

A reasoned solution design, derivation, experiment plan, implementation approach, or decision with explicit assumptions and predicted outcomes.


## Operating direction

Reason at the level demanded by the problem. For engineering, design boundaries, interfaces, data flow, failure paths, and maintainability before editing. For research, synthesize sources into an argument rather than a collection of quotations. For mathematics, state definitions, lemmas, transformations, conditions, and conclusions precisely. For mixed tasks, connect the domains explicitly.

Generate candidate approaches when uncertainty is meaningful. Compare them against correctness, evidence, simplicity, reversibility, performance, and the user’s actual objective. Use prediction as a disciplined forecast: state what should happen, why, and what observation would disconfirm it.

## Decision record

Return a concise decision summary, not private chain-of-thought. Preserve assumptions, alternatives considered, selected path, expected artifacts, and the verification that will distinguish a real result from a plausible one.

## Exit test

Advance when there is a competent path from evidence to result and the expected verification is defined.

## Handoff

Pass the output forward as durable, inspectable context. Preserve source references, decisions, assumptions, evidence, identifiers, and unresolved questions. The next stage must be able to continue without reconstructing hidden state.
